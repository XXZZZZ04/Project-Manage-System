# 项目管理原型

个人游戏 Demo 用的项目管理界面原型。数据只存在这台浏览器里，不连后端，也不会真的访问 GitHub。

可以点的内容：

- 左侧图标栏：展开/折叠、回收站、设置、标签
- 项目列表、新建项目、全局搜索、快速添加
- 中间页面：仪表盘、任务、看板、Bug、想法。设置和回收站从左侧图标进入，不是顶栏页签
- 右上角 Source Control：暂存、提交、推送、拉取、刷新
- 深色 / 浅色

示例里有两个项目：「星港余烬」和「纸船」。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 [http://127.0.0.1:43123](http://127.0.0.1:43123)。

改过的内容记在浏览器的 localStorage。设置页底部可以「重置示例数据」。
