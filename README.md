# 项目管理

个人游戏 Demo 用的项目管理软件，Windows 桌面版。界面沿用原来的原型。项目数据写在本机的一个 Git 仓库里，只同步项目文件，不同步软件本身。

第一次打开是空的，没有示例项目。左侧可以新建项目。浏览器里的原型仍然带「星港余烬」和「纸船」，方便对照界面。

## 直接打开

安装过依赖之后：

```bash
npm install
npm run desktop
```

会弹出窗口。数据在：

`%APPDATA%\项目管理\vault`

里面的 `projects`、`library.json`、`trash.json` 会进入 Git。登录用的令牌在同目录的 `session.json`，这个文件被忽略，不会提交。

## 和另一台电脑同步

1. 在 GitHub 建一个空仓库。
2. 打开软件的全局设置，填写仓库地址、分支、用户名和个人访问令牌。
3. 保存并登录。登录会真的连一次 GitHub。
4. 右侧源代码管理里暂存、提交、推送。
5. 另一台电脑安装这个软件，填同一个仓库，拉取。

令牌需要有该仓库的读写权限。

## 打成一个 exe

```bash
npm run pack
```

完成后在 `release` 里找 `ProjectManage` 的便携版。

## 只看浏览器原型

```bash
npm run dev
```

打开 http://127.0.0.1:43123 。这一路仍然把数据放在浏览器里，Git 是模拟的，不会连接 GitHub。
